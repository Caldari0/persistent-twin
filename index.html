Technical Architecture

The Twin is a visualization layer built on top of the user's persistent state. It does not store data itself; it renders the current state of the Progression Engine by aggregating three primary backend sources.

DB TABLE

user_skill_mastery

Calculates XP & Level per branch and analyzes rolling windows for Trend Analysis (Stable vs At Risk).

DB TABLE

activity_logs

Tracks Momentum via streak calculation and mission volume to provide context for continuity.

DB TABLE

engine_state

The Coach logic. Determines "Next Recommendation" and balances cognitive load (Challenge vs Reinforce).
